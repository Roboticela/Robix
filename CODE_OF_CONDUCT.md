# Code of conduct

Robix is built by people who write compilers, robot software, and the tools around them. This is the standard for issues, pull requests, reviews, and any other space that uses this repository.

## 🌟 Our standard

We welcome contributors of every background and level of experience.

We expect:

- Kind, specific, technical feedback.
- Curiosity about a design before assuming it is a mistake.
- Credit for the work you used, and honesty about what you ran.
- Patience while someone reproduces a failure.
- Care around safety. A robot, a kernel, and a compiler all deserve a clear report.

We do not accept:

- Insults, harassment, or personal attacks.
- Discrimination.
- Publishing someone else's private information.
- Sexual attention or imagery where it was not invited.
- Claiming a test passed, or a feature works, when it was not run.

## 🛠️ Where this applies

This conduct applies in this repository: issues, pull requests, commit messages, documentation, and discussions. It also applies when a person is representing this project in public.

## 📣 How to report

Open a GitHub issue for a public conduct problem, or a private security advisory when the report itself should stay private (see [SECURITY.md](SECURITY.md)). Describe what happened, where, and who was involved. You can ask that your name stay off the public thread.

A maintainer from Roboticela will read the report, reply, and decide what happens next. That can be a warning, an edit, or a block from the repository. A report made in good faith will not be punished.
